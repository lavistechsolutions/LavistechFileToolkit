4. WHAT THE TOOLS DO

4.1 The Application provides local tools for bulk file rename, duplicate
detection, file hashing, folder comparison, folder sync, file metadata,
image resizing, image format conversion, JPEG and WebP compression,
PDF merge, split, and rewrite, and ZIP and 7Z archives.

4.2 These tools run on Your computer. The Application does not upload the
files You select. You can drop files or folders onto an open tool.

4.3 Bulk rename can change file names on disk after You choose Apply.
A template may use {name}, {ext}, {n}, {date}, and {parent}. Preview
does not change files. Apply checks for duplicate destination names and
existing destination files before it starts. It is not a transaction:
if a later move fails, earlier files in that run may already have been
renamed. Undo restores the last apply when the original name is free.
File contents are not modified.

4.4 The duplicate finder reports groups of files that share a size and a
SHA-256 hash. Files that cannot be read are skipped. If You confirm,
extra copies are sent to the Recycle Bin. The oldest file in each group
is kept. The finder does not permanently delete files.

4.5 File hashes (MD5, SHA-1, SHA-256, SHA-512), folder comparison, and
the metadata view are for inspection. A matching hash shows that the
compared bytes match. It does not prove authorship.

4.6 Folder sync copies missing, newer, or different-sized files from a
source folder into a destination folder. If You choose the mode that
removes extras, and You confirm, files that exist only in the destination
are sent to the Recycle Bin. One folder must not sit inside the other.

4.7 Image resize writes PNG copies into a folder You choose. Format
conversion writes a separate file in the format You choose. JPEG and
WebP compression write a new copy at the quality You choose and leave
the original in place. JPEG conversion uses a quality setting of 92
unless You set another quality in Image Compress. Animated images are
handled from the first decoded frame.

4.8 PDF tools merge files in the order You selected, split a PDF into
single pages, or rewrite a PDF and compare the file size. Rewriting
recompresses PDF streams. It does not downsample images inside the PDF.

4.9 Archive tools create a ZIP or 7Z from selected files, and can list
or extract ZIP, 7Z, RAR, TAR, and GZ. Extract refuses to write outside
the output folder and refuses to overwrite a file that is already there.

4.10 Keep backups before bulk rename, folder sync, or sending duplicate
copies to the Recycle Bin.
